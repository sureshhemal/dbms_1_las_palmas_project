It is provided as `'wait'`, but nothing ever calls `inject('wait')`.

Only three API calls are used anywhere: `$wait.start(name)`, `$wait.end(name)` and `$wait.any()`. There are no `&lt;v-wait&gt;` components, no directives, and no `$wait.is(...)` calls.

**Pattern A: start/await/end around a fetch** (`Pages/Agents/Index.vue`):
```js
    async fetchAgents() {
      this.$wait.start('fetching-agents')

      const { data } = await $http.get('agents')

      this.agents = data

      this.$wait.end('fetching-agents')

      return data
    },
```

**Pattern B: end the wait in `.finally()` on writes** (`Pages/Agents/Index.vue`):
```js
      this.$wait.start('saving-agent')

      await $http[method](url, agent).finally(() =&gt; this.$wait.end('saving-agent'))

      this.success('Agent Saved')
```
`Pages/Passbooks/Show.vue` does the same for a blob download:
```js
      this.$wait.start('downloading-passbook')

      const response = await $http.get(`passbooks/${this.passbookId}/export`, {
        responseType: 'blob',
      }).finally(() =&gt; this.$wait.end('downloading-passbook'))
```

**Dynamic names** (`Pages/Banks/banks.js:61`):

